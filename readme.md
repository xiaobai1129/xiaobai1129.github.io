## 📖 项目简介

这是我的个人主页，整合了简历信息与个人自传内容，全方位展示学术背景、技术能力、项目经历以及成长故事。网站采用深色主题设计，搭配紫蓝渐变配色方案，视觉效果优雅、沉稳。

## 🏗️ 网站结构

| 板块 | 说明 |
|------|------|
| **Hero 首屏** | 渐变色大字名字 + 打字机动效循环展示身份标签 |
| **关于我** | 个人简介、成长背景与基本信息卡片 |
| **教育经历** | 时间轴展示从北部湾大学（嵌入式方向）到中国传媒大学硕士的学术旅程 |
| **技术栈** | 六大分类卡片：编程语言、AI/深度学习、数理基础、工具框架、专业课程、软技能 |
| **项目经历** | 五个核心项目卡片，涵盖 Web 应用、视频修复、多标签分类、图像拼接等 |
| **实习经历** | 汐基智能实习详情，自监督学习图像算法方向 |
| **我的故事** | 基于近四万字自传提炼的六个人生片段，从山东农村到北京学术殿堂 |
| **联系我** | 邮箱、GitHub、微信、地址四张联系卡片 |

## ✨ 技术特性

- **纯前端实现** — HTML + CSS + JavaScript，零框架依赖，部署简单
- **深色主题** — 专业感十足的暗色设计，搭配紫蓝渐变高亮
- **粒子背景** — Hero 区域浮动光点动画，营造科技感氛围
- **打字机效果** — 首屏循环展示 "Computer Vision Engineer"、"Deep Learning Researcher" 等身份标签
- **滚动动画** — 页面元素在进入视口时优雅淡入，增强浏览体验
- **完全响应式** — 适配手机、平板、桌面等不同设备尺寸
- **玻璃拟态风格** — 卡片与导航栏采用毛玻璃质感设计
- **平滑导航** — 点击导航链接可平滑滚动至对应板块

## 🎨 设计理念

- **配色方案**：以深邃黑 (`#0a0a0f`) 为底，搭配紫色 (`#6c63ff`) 与粉色 (`#ff6b9d`) 渐变，既专业又不失个性
- **字体选择**：英文使用 [Inter](https://fonts.google.com/specimen/Inter) 无衬线字体，中文标题使用 [Noto Serif SC](https://fonts.google.com/noto/specimen/Noto+Serif+SC) 宋体，兼顾可读性与美感
- **交互细节**：悬停变色、卡片浮起、时间线标记发光等微交互，让页面"活"起来
